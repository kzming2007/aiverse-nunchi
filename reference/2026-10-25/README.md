## 기존 구현의 범위

HTML의 `// BEGIN NUNCHI CORE`와 `// END NUNCHI CORE` 사이가 공통 계산 코드입니다. `plan`은 이전 기록으로 상대 시각을 정하고, `resolve`는 사람 입력과 비교합니다. UI는 클릭 입력과 5초 진행, 한 회차 10판, 결과 표를 포함합니다.

상대는 신호 A/B와 개인/누적 예측의 네 개입니다. 개인 예측은 과거 유효 입력 최대 8건의 회귀이며, 누적 데이터는 합성 자료입니다. 마지막 입력 탈락과 AI끼리 충돌은 기본 UI에 없습니다. 별도 비교 스크립트에서 다루는 규칙을 UI에 구현했다고 혼동하지 않습니다.

이 HTML은 호스트 화면용 소스입니다. 독립 웹앱의 패키지, CSS 환경과 서비스 연결을 갖춘 배포본은 아닙니다. 현황판 서버, 실제 방문객 저장, QR 접속과 USB 장치 설정도 포함하지 않습니다.

## 재현하거나 수정할 때

두 cjs 파일은 Node.js의 기본 모듈만 사용하며 HTML과 같은 폴더에 있어야 합니다. 먼저 이 폴더를 실험 작업 위치로 복사한 뒤 다음 명령으로 실행할 수 있습니다.

```sh
node nunchi-check.cjs
node nunchi-elimination-study.cjs
```

스크립트는 같은 폴더의 JSON 결과를 덮어씁니다. 이 보존본에서 바로 실행하지 않고 작업 복사본을 사용합니다. Node 버전과 새 실행 성공 여부는 아직 이번 저장소에서 검증하지 않았습니다.

새 실험의 변수와 횟수는 질문에 맞춰 정합니다. 기존 1,000회차, 5초, 10판과 ±0.3초를 의무 조건으로 둘 필요는 없습니다. 원래 결과와 다른 조건을 사용하면 별도 결과로 기록합니다.

합성 플레이 예측 적중률, 게임 생존율, 유형 분류 정확도, 사람이 느끼는 재미는 서로 다른 결과입니다. 이 자료만으로 현장 게임의 재미나 협력 강화학습 효과가 검증됐다고 설명하지 않습니다.
