# Aeye · AI 눈치게임

> **버튼 하나로 AI와 겨루는 눈치게임 한 판! 내 타이밍을 읽는 AI를 이길 수 있을까?**

가톨릭대학교 AI전자정보융합대학 축제 **「AI:VERSE」** 의 체험형 부스 프로젝트입니다. — 팀 **Aeye**

---

## 어떤 행사인가요? — AI:VERSE

**AI:VERSE**는 가톨릭대학교 AI전자정보융합대학의 축제입니다.
"AI로 펼쳐지는 우리의 새로운 세계"를 주제로, 학생들이 각자의 전공(AI · 전자 · 데이터 · 미디어 등)을 직접 체험해 볼 수 있는 **체험형 부스**를 하나씩 맡아 운영합니다.

- **일시**: 2026년 11월 27일(금)
- **장소**: 가톨릭대학교 김수환관 컨퍼런스홀

## 어떤 게임인가요?

여럿이 겹치지 않게 번호를 외치는 **눈치게임**을, 버튼 하나로 **AI와 겨루는 게임**으로 만들었습니다.

방문객 1명이 **AI 3명**과 함께 플레이합니다. 시작 신호가 울리면 각자 원하는 타이밍에 버튼을 한 번 누르는데,

- 다른 사람과 **거의 동시에(0.3초 안에)** 누르면 → 둘 다 탈락
- **가장 마지막에** 누르거나 시간 안에 못 누르면 → 탈락
- 살아남으면 **늦게 누를수록 높은 점수** — 버틸수록 고득점이지만 그만큼 위험합니다

한 판은 약 5초, 총 10판을 합니다.

이 게임의 핵심은 **AI가 나를 읽는다**는 점입니다. AI들은 내가 버튼을 누르는 습관과 그동안 방문객들의 플레이 경향을 바탕으로 **내 다음 타이밍을 예측**하고, 서로 협력해 나와 겹치도록 노립니다.
게임이 끝나면 내 입력 타이밍과 AI가 예측한 타이밍을 비교하면서, AI가 사람의 행동 패턴을 어떻게 분석하고 예측하는지 직접 체감할 수 있습니다.

## 들어갈 시스템

| 시스템 | 내용 |
|---|---|
| 🤖 **예측 AI** | 참가자의 입력 패턴과 방문객 전체의 경향을 학습해 다음 타이밍을 예측하고, 서로 다른 전략을 가진 AI 3명이 협력 |
| 📊 **결과 분석** | 내 타이밍 vs AI가 예측한 타이밍 비교, 플레이 성향(눈치 유형) 분석 |
| 🏆 **실시간 랭킹 현황판** | 부스의 큰 화면에 모든 참가자의 순위와 대결 결과를 실시간으로 표시 |
| 🔴 **물리 버튼** | 키보드 대신 큰 USB 버튼으로 플레이 |
| 📱 **모바일 참여** | 대기 인원이 많을 때 QR로 접속해 휴대폰에서 플레이 (현장 네트워크 테스트 후 결정) |

> 지금은 게임 화면과 랭킹 현황판의 **프로토타입**만 있고, 핵심인 **예측 AI는 아직 개발 전**입니다. (현재 AI는 랜덤으로 누릅니다)
