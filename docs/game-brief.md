# 게임 구상과 조정할 부분

팀 검토용 문서입니다. (2026-11-14 작성, 11/16 메인 저장소로 옮기며 현재 상태 반영)
출처와 제안 상태는 [제안 기록](ideas-and-decisions.md)에서 구분합니다.

## 만들고 싶은 경험

게임을 하면서 AI가 내 입력 습관을 읽고 대응한다는 느낌을 주고, 끝난 뒤에는 내 플레이를 짧게 되돌아보며 설명으로 이어지게 합니다. 단순 점수 표시뿐 아니라 “나를 이렇게 읽었구나”, “다음에는 다르게 해보고 싶다”는 만족감을 목표로 논의합니다.

두 게임 자리와 현황판, 모바일 웹 참여는 전체 준비 범위에 포함합니다. 첫 회차 데모부터 만들자는 것은 제작 순서입니다. 모바일은 기존 QR 휴대폰 접속 구상을 기준으로 하며 네이티브 앱 제작이 합의된 것은 아닙니다.

| 화면과 접점 | 준비할 흐름 | 현재 프로토타입 |
|---|---|---|
| 게임 자리 2곳 | 짧은 규칙 안내, 타이밍 선택, 상대의 반응, 판정과 결과 | 있음 (`?station=1`, `?station=2`) |
| 별도 현황판 | 기다리는 사람도 알아볼 대결 결과와 전체 플레이 경향 | 랭킹과 10판 기록 팝업만 있음 |
| 모바일 웹 | QR 접속 후 휴대폰에서 참여. 현장 혼잡과 연결 상태에 따른 운영 방식 검토 | 없음 |
| 결과와 설명 | 개인 기록에서 근거를 골라 짧은 해석과 시각 피드백 제공. 더 궁금한 사람에게 원리 설명 | 점수·판별 결과만 있음 |
| 다음 참가자 | 재시작과 개인 기록 초기화, 필요시 재도전, 다음 사람 안내 | 있음 (닉네임 입력으로 다시 시작) |

## 출발안과 조정 변수

계획서에는 사람 1명과 AI 3명, 약 5초씩 10판, 겹침과 마지막 입력을 피하는 방식이 적혀 있습니다. 이 게임의 큰 흐름을 출발점으로 삼되 다음은 실험과 팀 논의로 조정합니다.

- AI 수, 역할과 협력 방식
- 한 판의 길이, 전체 판수, 충돌 간격과 탈락 판정
- 상대 신호를 보여주는 방식, 난이도와 스테이지 전환
- 개인 기록, 사전 자료, 누적 플레이를 사용하는 방식
- 점수와 결과 표현, 현장 및 모바일의 참여 흐름

> 현재 프로토타입의 값: AI 3명(아직 무작위), 한 판 5초, 10판, 0.3초 안 동시 입력 탈락, 마지막 입력·시간 초과 탈락, 생존 시 누른 시각(초) × 100점.
> 대부분 `prototype/public/game.js` 맨 위 `CONFIG`에서 바꿀 수 있습니다.

고정된 적중률 목표는 아직 없습니다. 판정과 AI 수, 참가자의 전략에 따라 같은 적중률도 전혀 다른 체감이 됩니다. 강하게 저격하거나 사실상 이기기 어려운 단계도 제안 후보입니다. 이를 채택한다면 왜 어려운지, 도전 자체에서 어떤 재미를 얻는지, 다른 단계와 어떻게 이어지는지 함께 봅니다. 사전 예측과 입력 후 반응은 구분해 설명합니다.

## 연출 구상: 빠른 우주 아케이드

11/14 팀원 개인 제안이며 팀의 확정 콘셉트는 아닙니다. (현재 프로토타입에는 우주 배경만 적용)

- AI:VERSE에 맞춰 우주 테마를 가볍게 더한 아케이드 또는 픽셀 게임 연출
- 빠른 화면 반응과 효과음, 짧은 전환으로 눈치와 순발력을 함께 느끼게 하는 체험
- 한 번 참여하고 다음 사람에게 넘길 수 있는 짧은 회차와 순환 흐름
- 단계가 바뀌면 상대의 모습이나 행동도 바뀌어 AI의 대응 차이를 알아차리는 구성
- 게임 후 플레이 경향이나 AI가 읽은 행동을 결과로 보여주고 간단한 설명으로 연결

‘한 턴’이 입력 한 번인지, 여러 판으로 묶인 한 회차인지는 아직 정하지 않았습니다. 현재 문서에서는 짧게 완결되는 참여 경험으로만 해석합니다. 빠른 연출이 무조건 먼저 누르는 게임을 뜻하는 것도 아닙니다.

## AI를 보여주는 방법과 비교 후보

아래 비교 구성은 팀원의 아이디어를 바탕으로 Codex가 제안한 검토안입니다. 실제 모델 선택이나 실험 실행은 아직 하지 않았습니다.

| 비교할 요소 | 구상 | 함께 볼 것 |
|---|---|---|
| 단순 기준 | 무작위, 고정 규칙, 직전 입력, 간단한 회귀 | 복잡한 방법을 넣었을 때 실제로 무엇이 달라지는지 |
| 개인 적응 | 현재 참가자의 이전 입력으로 다음 행동 예상 | 몇 판 뒤 읽는 느낌이 생기는지, 전략을 바꾸면 얼마나 빨리 따라오는지 |
| 유형 가설 | 즉시 입력, 신호 반응, 기다림, 무작위 등의 가능성을 비교 | 한 판의 우연과 반복 습관을 구분하는지, 근거 부족도 표현하는지 |
| 사전 자료 | 합성 플레이나 의도적으로 만든 여러 전략, 실제 플레이 표본을 참고 | 현재 참가자의 기록이 묻히지 않는지, 자료에 없던 행동에도 작동하는지 |
| 협력 상대 | 신호로 반응을 유도하거나 서로 다른 타이밍을 맡는 정책 | AI 수와 공격 범위가 넓어진 효과인지, 적응이나 협력의 효과인지 |
| 강화학습 등 | 가상 플레이어를 상대로 정책을 학습하는 팀원 제안(P04, P06) 검토 | 학습 비용, 다른 전략으로의 전이, 단순 기준 대비 이점과 재미 |
| 결과 설명 | 행동 근거와 대표 장면, 짧은 유형 해석을 제시 | 참가자가 납득하는지, 검증하지 않은 성격 진단처럼 보이지 않는지 |

회귀로 충분한 부분과 다른 기법이 필요한 부분은 아직 결론 내리지 않습니다. 기존 회귀는 입력 시각을 맞히는 모델이며 유형 분류 결과를 검증한 것이 아닙니다. 유형 확률과 예측 적중률, 생존율은 서로 다른 지표입니다.

### Ablation을 한다면

처음부터 모든 조합을 돌릴 필요는 없습니다. 확인할 질문을 정한 뒤 비교합니다.

- 개인 적응 있음/없음: 같은 상대와 규칙에서 참가자의 최근 기록이 무엇을 바꾸는가?
- 사전 자료만/개인 기록만/함께 사용: 초반 대응과 이후 적응이 어떻게 달라지는가?
- 유형 가설 있음/없음: 전체를 한 모델에 섞을 때보다 도움이 되는가?
- 협력 있음/없음: AI 수와 입력 횟수, 허용 정보를 맞춰도 이점이 남는가?
- 스테이지 있음/없음: 가능한 한 같은 난이도 조건에서 연출이 이해와 재도전 의향을 바꾸는가?

각 비교에 예측과 생존 결과뿐 아니라 설명 가능성, 체험 길이와 사람의 반응을 함께 남깁니다. 1,000회차나 ±0.3초는 옛 실험 조건이지 새 실험의 정답이 아닙니다. 탐색에 쓴 입력과 최종 비교 입력을 구분하고, 좋은 결과 하나만으로 일반적인 효과를 확정하지 않습니다.
