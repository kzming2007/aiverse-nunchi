# 기존 시뮬레이션 요약

10/25의 **합성 플레이 결과**입니다. 실제 사람의 재미를 측정한 결과는 아니며 이번 정리에서 다시 실행하지 않았습니다. [코드와 기존 결과](../reference/2026-10-25/README.md)를 함께 볼 수 있습니다.

## 당시 결과

당시에는 5초씩 10판, 적중 범위 ±0.3초, 이전 입력 최대 8건의 간단한 회귀 모델을 사용했습니다. 행동별 가상 1,000회차를 비교했습니다. **모두 당시 조건이며 이번 게임의 고정 사양이나 목표 횟수가 아닙니다.**

| 가상 참가자의 행동 | 무작위 예측 적중률 | 개인 회귀 예측 적중률 |
|---|---:|---:|
| 신호 뒤 비슷한 간격으로 반복 입력 | 12.33% | 79.13% |
| 매번 비슷한 시각에 입력 | 12.10% | 82.21% |
| 중간부터 입력 전략 변경 | 12.09% | 32.06% |
| 매번 무작위 입력 | 12.07% | 11.67% |

반복 습관은 읽을 수 있었고 전략 변경에는 예측이 흔들렸습니다. 생성 규칙과 같은 고정 규칙은 첫 행동에서 99.95%를 기록했습니다. 학습 모델이 항상 더 낫지는 않았습니다. 위 적중률은 한 예측이 입력을 맞힌 비율이며 게임 승률과 다릅니다.

서로 다른 습관을 하나의 회귀식에 섞으면 자료가 늘어도 좋아지지 않는 조건이 있었습니다. 유형을 구분해 볼 이유는 되지만, 유형 분류기를 검증한 실험은 아닙니다.

## 지금 제안에 쓸 수 있는 부분

| 구상 | 참고할 부분 | 아직 확인할 것 |
|---|---|---|
| 유형을 읽는 체험 | 반복 시각, 신호 반응, 전략 변경을 행동 가설로 비교 | 실제 참가자를 짧은 회차 안에 얼마나 구분하는지 |
| 스테이지 | 기본 상대에서 개인 기록을 반영하는 상대로 변화시키는 후보 | 체감 난이도, 변화의 이해, 재도전 의향 |
| 사전 학습과 개인 적응 | 자료의 종류와 현재 참가자 기록의 역할을 나누어 보기 | 초반 정보 부족과 이후 적응의 균형 |
| 협력 AI | 개별 예측과 공동 공격을 구분해 비교 | 기존 bandit 실험은 각자 생존을 보상으로 했으므로 협력 강화학습의 검증이 아님 |

마지막 입력에 불이익이 없으면 기다리기가 유리해지고, 첫 충돌에서 끝내면 누르지 않는 참가자가 살아남는 조건도 있었습니다. AI 수와 판정 방식이 바뀌면 결과도 다시 비교해야 합니다. 규칙 비교의 다수 조건은 사람 1명과 상대 4명이었습니다.

**적중률을 높이는 것만으로 재미가 결정되지는 않습니다.** 상대를 보고 타이밍을 고민하는지, 나를 읽는 변화가 느껴지는지, 결과를 보고 납득하거나 다시 하고 싶은지 직접 확인할 필요가 있습니다. 비교할 변수와 ablation 후보는 [게임 구상](game-brief.md)에 정리했습니다.
