# 제안과 구체화 기록

팀이 아이디어의 출발점과 현재 선택을 함께 이해하기 위한 짧은 기록입니다. 개인 기여도를 평가하거나 발언을 모두 보관하는 문서는 아닙니다. 에이전트가 요약한 문장은 아래 출처의 취지를 정리한 것이며 직접 인용이 아닙니다.

> 공개 저장소이므로 출처는 이름 대신 **팀원 제안 / 운영계획서 / 에이전트(Codex, Claude)** 처럼 종류만 적습니다.

## 다음 기록 방법

추가할 때 아래 정도만 남깁니다. 팀이 어떤 제안을 채택하거나 바꾸면 원래 제안을 지우지 않고 짧게 연결합니다.

- 제안 ID와 출처 종류(팀원 제안 / 팀 결정 / 에이전트 이름), 날짜
- 바꾸려는 경험 또는 문제와 제안
- 상태: 제안 / 비교 중 / 팀 확인 / 구현 / 시험 결과
- 관련 제안이나 Issue, PR
- 새로 확인한 점 또는 아직 남은 점

예를 들어 P06을 구현하더라도, 에이전트가 새로 정한 유형 경계와 모델은 에이전트 제안으로 구분합니다. PR이 합쳐졌다는 사실만으로 재미가 확인됐다고 쓰지 않습니다.

## 공유 대상

개인 탐색 중인 생각은 각자의 작업 공간에 둡니다. 이 문서에는 팀과 논의할 부분만 출처 종류를 표시해 요약합니다. 현장 화면과 설명에는 구현하고 확인한 동작을 바탕으로 참가자에게 필요한 내용만 담습니다. 팀 검토 문서 전체를 현장 안내로 사용하지 않습니다.
